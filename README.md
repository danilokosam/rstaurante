# Restaurant Website CMS (MVP)

Web pública para un restaurante + panel de administración (CMS) para que el propio restaurante gestione su contenido.

Stack: Next.js 16 · Payload CMS 3 · Supabase PostgreSQL · Tailwind CSS 4 · TypeScript.
